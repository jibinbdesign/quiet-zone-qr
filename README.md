# Quiet Zone

A free QR code generator that runs entirely in the browser. There is no sign-up, watermark or expiry date, and nothing you enter is sent to a server.

- **Content:** link, text, Wi-Fi, contact card, email, phone call, SMS, location or calendar event
- **Styling:** module and eye shapes, colours, gradients, logos, labels, error correction and quiet zone
- **Scan test:** checks each design as you change it and warns about low contrast or oversized logos
- **Export:** PNG up to 4096 px, or SVG

## Run it

Open `index.html` in a browser. It's a single file with no build step. It loads fonts from Google Fonts and two libraries from public CDNs, [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) and [jsQR](https://github.com/cozmo/jsQR), so it needs an internet connection.

Scan a code with a real phone before printing a large run.
